Backup · မှတ်တမ်းသိမ်း

Save everyone's progress, start dates and pagodas as a file on your phone. Keep it in Downloads, Google Drive or a chat. If the app is removed, the phone is changed, or Chrome data is cleared, restore it from that file.

Each day follows the chart: say the day's Buddha attribute for the listed number of rounds. When every round is done, the day turns green. The next day opens automatically at 00:00, but only if today is completed. If a day is missed, the practice starts again from Level 1, Day 1 on the next Monday (today, if today is Monday). The calendar shows completed days, today, the planned days ahead and any missed day. Each person has their own progress. Tap a name at the top to switch, or tap the selected name to rename or remove it. Progress is saved on this phone.
